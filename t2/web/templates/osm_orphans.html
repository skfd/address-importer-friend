For every pure-address node and entrance node in the cached OSM Toronto extract, this scan checks whether the City source has an active row with the same normalized (addr:street, addr:housenumber). Source ranges (lo_num != hi_num) are parity-expanded into per-integer keys, so OSM 153 Foo St matches a source 151-155 Foo St row.
